Миграция ключей

Массовая миграция и точечная выдача собраны в одном разделе.

Миграция существующих активных ключей со старых host-ов на MainPanel по выбранному тарифу. Expired ключи пропускаются автоматически.

Параметры миграции

Целевой host всегда MainPanel. Тариф определяется из users.db; сомнительные клиенты попадут в ручную проверку.

Новый срок = текущий срок старого ключа + бонусные дни. Expired ключи не возрождаются.

Ручная выдача ключа пользователю по Telegram ID: можно выдать новый ключ или заменить текущий.

Параметры выдачи

Ключ не выбран. В режиме замены будет выбран автоматически по хосту.

Супер: WHITELIST — 40 ГБ/мес. Стандарт: WHITELIST — 5 ГБ/мес. Остальные серверы — безлимитные.

Выбранный бот будет использован для Telegram-уведомления и сохранён как источник ключа.

Месяцы и годы считаются календарно. Можно комбинировать дни, месяцы и годы.

В режиме замены старый ключ на выбранном хосте архивируется после успешной выдачи нового.

Текст уведомления

Плейсхолдеры: {host}, {expiry}, {key}, {email}, {key_id}, {whitelist_policy}
